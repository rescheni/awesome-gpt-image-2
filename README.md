# Prompt Atelier · 图像提示词工作室

一个自托管的 AI 图像提示词生成网站：**选模板 → 分模块精调 → 组装/LLM 增强 → 一键复制**。

## ✨ 功能

### 游客可用（无需登录）
- 📋 **22 套工业级中文模板**：UI 截图、信息图、海报排版、商品视觉、品牌身份、建筑空间、写实摄影、街头抓拍、插画、角色设定、3D 潮玩、场景叙事、古风历史、文档出版等
- 🎛️ **分模块编辑**：主体场景 / 视觉风格 / 构图布局 / 光线氛围 / 色彩 / 画面文字 / 负面约束 / 补充说明，**每一块都可自由修改**
- 🎥 **121 条专业摄影参数**（7 大类）：
  - 相机机身 16 项（哈苏 X2D、徕卡 M11、富士 GFX、宝丽来 SX-70、CCD 老数码…）
  - 镜头焦段 16 项（14mm 超广角 → 400mm 超长焦、移轴、鱼眼、变形宽银幕、Helios 旋焦…）
  - 光圈景深 12 项（f/0.95 → f/16、长曝 ND、景深合成…）
  - 胶片型号 17 项（Kodak Portra/Ektar/Tri-X、Fujifilm Velvia/Superia、Cinestill 800T、Ilford…）
  - 滤镜风格 20 项（Teal&Orange、日系清新、莫兰迪、赛博朋克、漂白、交叉冲洗、红外…）
  - 光线方案 20 项（Golden Hour、伦勃朗光、蝴蝶光、霓虹、烛光、高调/低调…）
  - 摄影技术与质感 20 项（摇拍、双重曝光、荷兰角、镜头眩光、自然颗粒…）
- 📚 **541 个逆向工程案例**：可搜索、点击载入
- ✦ **组装提示词**：纯前端拼装，**修改不持久化**（刷新即恢复），可复制

### 登录后解锁
- 🤖 **AI 智能增强**：接入任意 OpenAI 兼容接口，由语言模型润色生成专业提示词
- ⚙️ **模型设置**：Base URL / API Key / 模型名，保存在服务端配置文件
- 🎨 **自定义模板**：创建 / 编辑 / 删除自己的模板体系
- 🔒 登录入口默认隐藏（右下角小齿轮），不打扰游客浏览

## 🚀 部署

```bash
# 1. 依赖
pip install flask flask-cors

# 2. 配置（首次启动会自动生成随机管理员密码并打印在终端）
cp config.example.json config.json   # 或直接让程序自动生成
vim config.json                       # 修改管理员账号密码

# 3. 启动
python3 app.py
# → http://0.0.0.0:8001
```

### 环境变量（可选）
无。全部配置集中在 `config.json`（已加入 `.gitignore`，不会上传）。

## 🔐 安全说明

- `config.json`（含管理员密码、API Key、session secret）**已在 .gitignore 中排除**，不会提交到仓库
- 首次启动自动生成随机密码，不使用弱口令
- 未登录用户无法调用 LLM 生成、无法读写模型配置、无法管理自定义模板

## 📁 结构

```
gpt-prompt-studio/
├── app.py                  # Flask 后端（登录/模板/参数/生成/LLM配置）
├── config.json             # 本地配置（gitignore，含凭据）
├── config.example.json     # 配置模板（可提交）
├── custom_templates.json   # 自定义模板存储（gitignore）
├── templates/
│   └── index.html          # 单页前端（暗色美学 / 三栏工作室）
└── data/
    ├── style-library.json  # 22 套模板 + 分类 + 标签
    ├── photo-styles.json   # 121 条专业摄影参数
    └── cases.json          # 541 个案例
```
